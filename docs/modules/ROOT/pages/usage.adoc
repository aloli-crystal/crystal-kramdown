= Usage

== Basic Conversion

[source,crystal]
----
require "kramdown"

doc = Kramdown::Document.new("# Hello **world**")

html = doc.to_html   # => "<h1>Hello <strong>world</strong></h1>\n"
text = doc.to_text   # => "Hello world\n"
ast  = doc.root      # => Kramdown::Element (AST root)
----

== CLI

[source,bash]
----
crystal-kramdown input.md                 # HTML to stdout
crystal-kramdown input.md -o output.html  # HTML to file
crystal-kramdown input.md --to text       # plain text
crystal-kramdown -v                       # version
crystal-kramdown -h                       # help
----

== AST Access

[source,crystal]
----
doc = Kramdown::Document.new("# Title\n\nParagraph with **bold**.")
root = doc.root

root.children.each do |el|
  puts "#{el.type}: #{el.value}"
end
----
