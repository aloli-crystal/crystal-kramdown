= Utilisation

== Conversion basique

[source,crystal]
----
require "kramdown"

doc = Kramdown::Document.new("# Bonjour **monde**")

html = doc.to_html   # => "<h1>Bonjour <strong>monde</strong></h1>\n"
text = doc.to_text   # => "Bonjour monde\n"
ast  = doc.root      # => Kramdown::Element (racine de l'AST)
----

== CLI

[source,bash]
----
crystal-kramdown input.md                 # HTML sur stdout
crystal-kramdown input.md -o output.html  # HTML dans un fichier
crystal-kramdown input.md --to text       # texte brut
crystal-kramdown -v                       # version
crystal-kramdown -h                       # aide
----

== Acces a l'AST

[source,crystal]
----
doc = Kramdown::Document.new("# Titre\n\nParagraphe avec du **gras**.")
root = doc.root

root.children.each do |el|
  puts "#{el.type}: #{el.value}"
end
----
